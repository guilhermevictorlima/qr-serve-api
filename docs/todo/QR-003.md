em bancos criados antes. Para atualizar um banco existente:

```sql

ALTER TABLE pedido ADD COLUMN data_hora_conclusao TIMESTAMP;
CREATE UNIQUE INDEX uq_sessao_mesa_ativa_por_mesa ON sessao_mesa (mesa_id) WHERE data_hora_encerramento IS NULL;
```
